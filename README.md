# Login HTML5/CSS

Una interfaz de inicio de sesión (Login) moderna, limpia y 100% responsiva, lista para ser integrada en cualquier panel de administración.

## Características Principales

* **Diseño Responsivo:** Adaptación perfecta entre escritorio (dos paneles) y móvil (un solo panel limpio) usando Media Queries.
* **Layout Moderno:** Estructura construida con **CSS Grid** para la división de la pantalla y **Flexbox** para el centrado de elementos.
* **Interactivo:** Botón funcional para mostrar/ocultar la contraseña desarrollado con **Vanilla JS** (JavaScript puro).
* **Buena UX/UI:** Efectos visuales de foco (`:focus-within`), transiciones suaves y botones reactivos.
* **Accesibilidad (A11y):** Uso de HTML semántico y técnicas de CSS para mantener las etiquetas legibles para lectores de pantalla en dispositivos móviles.

## Tecnologías Utilizadas

* **HTML5** (Estructura semántica)
* **CSS3** (Grid, Flexbox, Pseudo-clases y Animaciones)
* **JavaScript** (Manipulación del DOM)
* **Recursos Externos:** Google Fonts (Inter) y Google Material Symbols.
